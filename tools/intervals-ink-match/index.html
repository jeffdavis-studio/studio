Intervals — ink match · eight Sakura Pigma Micron pens

Values are HSB exactly as Intervals_v4.js stores them — ink1 = color(H, S, B). ink7 (Purple) is deliberately skipped: Jeff cut it from the set on 2026-09-10. The code ids stay as they are so the wheel order does not shift. Changes save automatically.

How to use this

  1. Hold the plotted swatch sheet next to the screen, in the light you normally judge in.
  2. For each pen, move H / S / B until the block on screen matches the ink on the paper. Paper white is the default surround; switch to mid gray if you need to judge saturation.
  3. The thin strip under each block is the old placeholder on the left, your value on the right, with the ΔE between them.
  4. When all eight look right, hit Copy all and text it to Morgan. (Or Download JSON if you would rather send a file.)

Sliders are HSB, so hue 0 is red and runs the way you read a colour wheel. The numbers are exactly what goes into color(H, S, B) in the generator — no conversion in between.

Everything saves as you go, so you can close the lid and come back. Reset on a card, or Reset all, puts the placeholders back.
