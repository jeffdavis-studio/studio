# Intervals hash picker

Live: https://jeffdavis-studio.github.io/studio/tools/intervals-picks/ . Params: `?v=9|9.1` (both from `intervals/` on main since the 10-11 merge; v10 removed 10-11), `?seed=`, `?page=`, `?n=` (default 24, cap 60), `?hashes=0x..,0x..` (exactly those), `#f=..&h=..` (fave / hmmm marks). The address bar is the whole state: mark tiles, press Share, text the URL; opening it restores the marks (and replaces that browser's saved marks for the version). Export gives the fave hashes, the `let curated = [...]` line and a faves-only page. Tiles are `frame.html`, which loads p5 1.11.3, `dev-token-v<n>.js` and the program unmodified.
